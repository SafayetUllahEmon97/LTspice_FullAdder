.include tsmc018.lib

VDD vdd 0 1.8

* Inputs (pulse for testing)
VA A 0 PULSE(0 1.8 0 10p 10p 5n 10n)
VB B 0 PULSE(0 1.8 0 10p 10p 10n 20n)
VC C 0 PULSE(0 1.8 0 10p 10p 20n 40n)

* XOR1 = A ⊕ B
M1 n1 A vdd vdd PMOS
M2 n1 B vdd vdd PMOS
M3 n1 A n2 0 NMOS
M4 n2 B 0 0 NMOS

* XOR2 = (A ⊕ B) ⊕ C → SUM
M5 SUM n1 vdd vdd PMOS
M6 SUM C vdd vdd PMOS
M7 SUM n1 n3 0 NMOS
M8 n3 C 0 0 NMOS

* Carry = AB + BC + CA
M9 n4 A vdd vdd PMOS
M10 n4 B vdd vdd PMOS
M11 n5 B vdd vdd PMOS
M12 n5 C vdd vdd PMOS
M13 n6 A vdd vdd PMOS
M14 n6 C vdd vdd PMOS

M15 CARRY A n7 0 NMOS
M16 n7 B 0 0 NMOS
M17 CARRY B n8 0 NMOS
M18 n8 C 0 0 NMOS
M19 CARRY A n9 0 NMOS
M20 n9 C 0 0 NMOS

.tran 50n
.end
